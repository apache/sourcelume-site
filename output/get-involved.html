Get involved

Everyone interested in AI training-data provenance is welcome to follow the work and take part. Apache Sourcelume follows the Apache Way, and its discussion list is open to everyone — no ASF affiliation required.

Join the discussion

  • Mailing list: dev@sourcelume.apache.org. Send an email to dev-subscribe@sourcelume.apache.org to subscribe, or browse the archives.
  • Chat: ask to be invited to the #sourcelume channel on the ASF Slack.

Introduce yourself, share what you're working on, and tell us where you'd like to help — whether that's the specification, the registry, attestation tooling, or connectors to existing data sources. Volunteers are currently organizing around the project's core components — Spec, Registry, Attest, CLI, Explorer, and Connectors — reply on the mailing list if you'd like to get involved in one.

Contribute to this website

This site lives in the apache/sourcelume-site repository. Pages are written in Markdown under content/pages/, and the site is built with Pelican.

  • For a small fix, edit a page directly on GitHub (the pencil icon) and open a pull request.
  • For larger changes, open a branch or a GitHub issue to discuss first.

Help build the project

Sourcelume brings together contributors from across the AI provenance and open data ecosystem — dataset curators, model producers, and communities working on adjacent standards. If you would like to help with a specific area, say hello on the mailing list and we will point you to where the work is happening.

More detailed contribution guidance will be added here as the project's processes take shape.
